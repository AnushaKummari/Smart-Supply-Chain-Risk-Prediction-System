Smart Supply Chain Risk Prediction System (SSRP)

An enterprise-grade logistics intelligence platform that predicts shipment delays, calculates supply chain risk, and provides real-time analytics dashboards.

Tech Stack:
- Spring Boot
- React
- Python ML (Scikit-Learn / XGBoost)
- PostgreSQL
- Docker
- WebSockets

Features:
- Shipment risk prediction
- Delay probability estimation
- Real-time alerts
- Supplier analytics
- Logistics dashboard
